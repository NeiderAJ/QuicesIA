Simulación de Intercepción de Misiles

Planteamiento del Problema

El sistema calcula la trayectoria para interceptar un misil enemigo. Reduciendo el problema a 2D, se igualan las posiciones espaciales en un tiempo de intercepción \(t_{int}\):

Enemigo (Tiro Parabólico):

$$y_e(t) = h_0 + v_{0e}\sin(\theta)t - \frac{1}{2}gt^2$$ $$x_e(t) = v_{0e}\cos(\theta)t$$

Interceptor (Con Propulsor):

$$y_d(t) = v_{0dy}t + \frac{1}{2}(a_p - g)t^2$$ $$x_d(t) = x_{d0} - v_{0dx}t$$

Análisis Funcional

La simulación evalúa la altura proyectada de intercepción. Si la intercepción analítica resulta a baja altura (menos de 300m), el interceptor activa propulsores adicionales. En este escenario, la aceleración extra \(a_p\) del interceptor contrarresta la gravedad para forzar la colisión geométrica en \((x_{int}, y_{int})\).

Conclusiones

1. La reducción al plano 2D simplifica drásticamente el coste computacional, siendo vital para sistemas de respuesta en tiempo real como el Iron Dome.
2. La implementación estocástica demuestra que la ventana de intercepción requiere propulsión activa cuando la detección ocurre demasiado cerca al suelo, compensando el déficit de tiempo de caída libre.
