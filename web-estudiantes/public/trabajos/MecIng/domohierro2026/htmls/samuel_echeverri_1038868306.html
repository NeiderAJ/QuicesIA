1. Enunciado del Problema

Un radar detecta un misil enemigo en vuelo parabólico. Se requiere diseñar un sistema de defensa que, tras identificar la trayectoria en un plano 2D, lance un proyectil defensor para neutralizar la amenaza. El lanzamiento del enemigo es estocástico dentro de un rango de 15° a 75°.

2. Solución Algebraica (Cinemática)

Para que ocurra la interceptación, las partículas deben ocupar la misma posición en el mismo instante de tiempo \(t_{int}\):

$$\vec{r}_e(t_{int}) = \vec{r}_d(t_{int})$$

Descomponiendo en los ejes coordenados para el misil enemigo (e) y defensor (d):

$$x_{e0} + v_{ex}t = x_{d0} + v_{dx}t$$ $$y_{e0} + v_{ey}t - \frac{1}{2}gt^2 = y_{d0} + v_{dy}t - \frac{1}{2}(g - a_p)t^2$$

El sistema resuelve para las componentes de velocidad del defensor despejando de las ecuaciones de posición:

$$v_{dx} = \frac{(x_{e0} - x_{d0}) + v_{ex}t}{t}$$ $$v_{dy} = \frac{(y_{e0} - y_{d0}) + v_{ey}t + \frac{1}{2}a_p t^2}{t}$$
Análisis del Ángulo de Lanzamiento (\(\theta_d\)): Una vez calculadas las componentes vectoriales de la velocidad inicial necesarias para el impacto (\(v_{dx}\) y \(v_{dy}\)), el ángulo de elevación del lanzador se determina mediante la función arcotangente: $$\theta_d = \tan^{-1}\left( \frac{v_{dy}}{v_{dx}} \right)$$ Este ángulo representa la dirección del vector velocidad inicial \(\vec{v}_d\) respecto al eje horizontal.

3. Análisis Funcional o Teórico

El análisis se fundamenta en el principio de independencia de los movimientos (Galileo). En el eje horizontal, se asume un Movimiento Rectilíneo Uniforme (MRU) dado que la resistencia del aire se considera despreciable para efectos de este modelo de física básica. En el eje vertical, se presenta un Movimiento Rectilíneo Uniformemente Variado (MRUV) bajo la acción de la aceleración de la gravedad (\(g\)).

Un aspecto crítico es la determinación del tiempo de encuentro (\(t_{int}\)). Para que la interceptación sea físicamente posible, este tiempo debe ser menor al tiempo total de vuelo del misil enemigo hasta el impacto con el suelo (\(t_{vuelo} = \frac{2v_{0y}}{g}\) si parte desde \(y=0\)). El sistema debe recalcular dinámicamente si se requiere asistencia de propulsores (\(a_p\)) para compensar trayectorias de interceptación que demanden velocidades iniciales superiores a la capacidad del lanzador.

4. Planteamiento de la Simulación

La simulación se implementa mediante un motor de pasos discretos (\(dt = 0.05s\)). La naturaleza estocástica del ejercicio se garantiza mediante el uso de generadores de números pseudoaleatorios para definir la posición inicial en Y y el ángulo de ataque del enemigo.

// Ejemplo de lógica estocástica implementada:
enemy.y0 = Math.random() * 200 + 200;
angle = Math.random() * (75 - 15) + 15;

Cada cuadro de la animación actualiza las posiciones basándose en las ecuaciones de Euler, permitiendo visualizar la colisión cuando la distancia euclidiana entre ambos proyectiles es inferior al umbral crítico definido (\(15m\) a escala).

6. Relación con el Sistema Domo de Hierro

El sistema real "Iron Dome" (Cúpula de Hierro) utiliza un radar EL/M-2084 para detectar la trayectoria del misil entrante en milisegundos. Al igual que en esta simulación, el sistema estima el punto de impacto. Una diferencia clave es que el Domo de Hierro solo lanza el interceptor "Tamir" si el cálculo indica que el misil caerá en una zona habitada o infraestructura crítica, optimizando así los recursos.

Esta simulación modela la etapa de guiado proporcional y la resolución de las ecuaciones cinemáticas que permiten al interceptor coincidir con el blanco, un concepto fundamental en los sistemas de defensa de punto modernos.

7. Conclusiones

La precisión del sistema depende de la resolución de las ecuaciones cinemáticas en tiempo real. Se concluye que ángulos de lanzamiento bajos aumentan la velocidad necesaria del interceptor para evitar el impacto en tierra del proyectil agresor.
