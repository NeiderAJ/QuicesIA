Intercepción de Proyectiles 2D — Simulador

Inspirado en la Cúpula de Hierro. Ajusta parámetros, genera amenazas y observa cómo el interceptor calcula una solución de colisión.

Enunciado

Se modela un escenario 2D con gravedad constante g = 9.81 m/s². Un proyectil enemigo (misil) es detectado con:

• Posición inicial: \(\vec r_0 = (x_0, y_0)\)

• Velocidad inicial: \(\vec v_0\)

• Dirección dada por cosenos directores: (\(l, m) = (\cos \theta, \sin \theta)\)

El sistema lanza un proyectil defensor desde \(\vec r_D = (x_D, y_D)\) para interceptarlo.

El movimiento se describe por las ecuaciones de cinemática:

  • Enemigo (solo gravedad): \(x_E = x_0 + v_0 l\, t\), \(y_E = y_0 + v_0 m\, t - \frac12 g t^2\)
  • Defensor: dos modos operativos Modo A: tiro parabólico clásico Modo B: con propulsor de aceleración constante \(a_T\)
  • Se busca un tiempo de interceptación \(t_c\) y parámetros del defensor para cumplir: \(\vec r_D(t_c) = \vec r_E(t_c)\)

Este escenario permite estudiar la intercepción de proyectiles en 2D considerando diferentes estrategias de lanzamiento y aceleración, reflejando las decisiones del sistema de defensa.

Solución (cierre de fuego)

Para interceptar al proyectil enemigo, se busca que el defensor llegue al mismo punto en el mismo instante que el enemigo. Se define un tiempo candidato de encuentro \(\tau = t_c - t_\text{lanza}\), donde \(t_c\) es el tiempo de colisión y \(t_\text{lanza}\) el momento en que el defensor es lanzado.

1. Se calcula el vector relativo desde el defensor hasta el enemigo, ajustando por la gravedad:

\(\vec R = [x_E(t_c) - x_D,\; y_E(t_c) - y_D + \tfrac12 g \tau^2]\)

2. Dependiendo del modo, se obtiene la velocidad necesaria:

Modo A (sin propulsor): velocidad constante \(\vec v_D = \vec R / \tau \Rightarrow v_D = \lVert\vec R\rVert / \tau, \hat u = \vec R / \lVert\vec R\rVert\) Deriva de la cinemática rectilínea uniforme: \(\vec s = \vec v t\).

Modo B (con propulsor): aceleración constante \(\lVert\vec R\rVert = v_{D0}\tau + \tfrac12 a_T \tau^2, \hat u = \vec R / \lVert\vec R\rVert, \phi = \arg(\vec R)\) Deriva de la cinemática uniformemente acelerada: \(\vec s = \vec v_0 t + \frac12 \vec a t^2\).

3. Se barre \(\tau\) en un rango de tiempos posibles y se selecciona la primera solución que cumpla los límites de velocidad y aceleración definidos por el usuario.

Ejemplo numérico paso a paso:

  • Posición inicial enemigo: x_E = 500 m, y_E = 120 m
  • Posición defensor: x_D = 0 m, y_D = 0 m
  • Gravedad: g = 9.81 m/s²
  • Tiempo candidato de encuentro: τ = 4 s

Paso 1: vector relativo ajustado por gravedad: \(\vec R = [500 - 0, 120 - 0 + \tfrac12 * 9.81 * 4^2] = [500, 198.2]\,\mathrm{m}\)

Paso 2: Modo A (sin propulsor) → velocidad requerida: \(v_D = \frac{\sqrt{500^2 + 198.2^2}}{4} \approx 136.6\,\mathrm{m/s}\) Dirección: \(\hat u \approx [0.91, 0.36]\)

Paso 3: Modo B (con propulsor) → velocidad inicial y aceleración ajustadas: \(\lVert\vec R\rVert = v_{D0}\tau + \tfrac12 a_T \tau^2\) Se despeja \(v_{D0}\) según los límites del sistema y \(\hat u = \vec R / \lVert\vec R\rVert\)

Con esto, el defensor sigue la trayectoria correcta y alcanza al enemigo exactamente al instante τ, respetando los límites físicos definidos.

Análisis

El sistema de defensa determina automáticamente la estrategia más adecuada según la posición inicial del proyectil enemigo:

Modo A (sin propulsor): Se utiliza cuando el enemigo se detecta a una altura significativa (\(y_0\) por encima de un umbral predefinido). El defensor realiza un tiro parabólico clásico, donde la velocidad inicial se calcula para recorrer la distancia hasta el enemigo en el tiempo τ:

\(\vec v_D = \frac{\vec R}{\tau} \Rightarrow v_D = \frac{\lVert \vec R \rVert}{\tau}, \quad \hat u = \frac{\vec R}{\lVert \vec R \rVert}\)

Esto deriva de la ecuación de movimiento rectilíneo uniforme: \(\vec s = \vec v t\), ajustando la trayectoria por gravedad.

Modo B (con propulsor): Se activa cuando el enemigo está muy cerca del suelo o requiere un intercepto más rápido. Aquí se añade aceleración constante (\(a_T\)) para garantizar que el defensor cierre la distancia en menor tiempo:

\(\lVert \vec R \rVert = v_{D0} \tau + \frac12 a_T \tau^2, \quad \hat u = \frac{\vec R}{\lVert \vec R \rVert}, \quad \phi = \arg(\vec R)\)

Se deriva de la cinemática uniformemente acelerada: \(\vec s = \vec v_0 t + \frac12 \vec a t^2\), permitiendo controlar velocidad y empuje según los límites del sistema.

La selección de \(\tau\) se realiza explorando un rango de tiempos posibles y verificando que la solución cumpla:

  • Rangos de velocidad del defensor (\(v_\text{min} \le v_D \le v_\text{max}\))
  • Valores máximos de aceleración (\(a_T\)) en Modo B
  • Condiciones de alcance físico: no superar la altura máxima o distancia máxima de la escena

Conclusión del análisis: La lógica del sistema permite que el defensor adapte su estrategia según la posición inicial del enemigo, utilizando el Modo A para situaciones normales y el Modo B cuando se requiere una respuesta rápida. Esto asegura una intercepción confiable respetando los límites físicos definidos.

Conclusiones

  • El cierre de fuego puede formularse buscando un t_c factible dentro de los límites cinemáticos del sistema.
  • El uso de propulsores amplía el dominio de soluciones, especialmente en escenarios de baja altura o con tiempos de reacción reducidos.
  • La representación en 2D facilita la visualización de trayectorias y la sintonía de parámetros operativos como velocidad, aceleración y ángulo de lanzamiento.

En resumen, la combinación de análisis cinemático, selección de modos de lanzamiento y ajustes de parámetros permite diseñar un sistema de intercepción eficiente y confiable.
