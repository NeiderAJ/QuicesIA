1. Enunciado del problema

Un radar detecta un misil enemigo en vuelo. Se conocen su posición inicial r₀ y velocidad inicial v₀. El sistema de defensa calcula automáticamente el propulsor necesario para que el misil defensor siempre intercepte al enemigo en el aire.

2. Solución algebraica propuesta

Planteamos el movimiento en 2D para ambos proyectiles: 

Enemigo:
xₑ(t) = xₑ₀ + vₑ·cosθₑ · t
yₑ(t) = yₑ₀ + vₑ·sinθₑ · t - (1/2)·g·t²

Defensor:
x_d(t) = x_d₀ + v_d·cosθ_d · t
y_d(t) = y_d₀ + v_d·sinθ_d · t + (1/2)·a·t² - (1/2)·g·t²

1. Para que haya intersección, necesitamos que en un mismo instante t* se cumpla: 

xₑ(t*) = x_d(t*)
→  xₑ₀ + vₑ·cosθₑ · t* = x_d₀ + v_d·cosθ_d · t*

2. Con esto despejamos el tiempo de encuentro en x: 

t* = (xₑ₀ - x_d₀) / (v_d·cosθ_d - vₑ·cosθₑ)

3. Luego igualamos posiciones en y usando ese tiempo: 

yₑ(t*) = y_d(t*)
→  yₑ₀ + vₑ·sinθₑ · t* - (1/2)·g·t*² = y_d₀ + v_d·sinθ_d · t* + (1/2)·a·t*² - (1/2)·g·t*²

4. De ahí despejamos la aceleración adicional a: 

a = (2 / t*²) · [ yₑ₀ + vₑ·sinθₑ · t* - (1/2)·g·t*² - (y_d₀ + v_d·sinθ_d · t* - (1/2)·g·t*²) ]

Con este valor de a, el misil defensor intercepta siempre al enemigo en el punto calculado.

3. Análisis funcional o teórico

El enemigo describe un tiro parabólico clásico. El defensor, con el propulsor calculado, ajusta su trayectoria parabólica para llegar exactamente al mismo punto y en el mismo instante.

4. Planteamiento de la simulación

Se generan aleatoriamente los parámetros iniciales del enemigo. El sistema calcula el propulsor necesario para garantizar la intercepción. El usuario puede modificar la gravedad, la velocidad inicial del defensor y su ángulo, observando cómo cambia el valor de propulsor requerido.

6. Relación con el sistema Domo de Hierro

Como el Domo de Hierro, este sistema calcula en tiempo real las condiciones exactas para interceptar un proyectil enemigo, ajustando los parámetros del misil defensor.

7. Conclusiones

El cálculo automático del propulsor asegura siempre la intercepción. La simulación muestra cómo la matemática del tiro parabólico se traduce en una defensa efectiva.
