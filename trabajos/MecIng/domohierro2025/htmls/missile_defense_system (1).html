🚀 Sistema de Defensa de Misiles

Análisis y Simulación de Interceptación Parabólica en 2D

Universidad de Antioquia - Física Mecánica

1. Enunciado del Problema

Un radar detecta un misil enemigo en vuelo. En el instante de detección se conocen:

  • Posición inicial r⃗₀: Vector posición del misil enemigo
  • Velocidad inicial v⃗₀: Vector velocidad inicial
  • Cosenos directores (l, m, n): Determinan la dirección en 3D

Condiciones del problema:

  • El misil enemigo se mueve únicamente bajo la acción de la gravedad terrestre
  • El problema se reduce de 3D a un plano 2D que contiene la trayectoria
  • El sistema de defensa debe calcular la dirección y velocidad del misil defensor
  • Si la detección es tardía, el defensor debe usar propulsores adicionales
Objetivo: Desarrollar un sistema que determine la estrategia óptima de interceptación basada en las condiciones de detección del misil enemigo.

2. Solución Algebraica Propuesta

2.1 Reducción de 3D a 2D

La trayectoria del proyectil siempre está contenida en un plano vertical que pasa por:

  • El punto de lanzamiento
  • La dirección inicial de velocidad
  • El vector de gravedad (vertical hacia abajo)
Ecuaciones paramétricas en 2D:
x(t) = x₀ + v₀ₓ·t
y(t) = y₀ + v₀ᵧ·t - ½g·t²

Donde:
v₀ₓ = |v₀|·cos(θ)
v₀ᵧ = |v₀|·sen(θ)
g = 9.81 m/s²

2.2 Condiciones de Interceptación

Para que ocurra la interceptación, ambos misiles deben estar en el mismo punto (x,y) al mismo tiempo t:

Condición espacial:
x_enemigo(t) = x_defensor(t)
y_enemigo(t) = y_defensor(t)

Condición temporal:
t_interceptación > 0 (interceptación futura)
t_interceptación < t_impacto_enemigo (antes del impacto)

2.3 Caso sin Propulsor (Trayectoria Parabólica Clásica)

Misil Defensor:
x_d(t) = x_d₀ + v_d₀ₓ·t
y_d(t) = y_d₀ + v_d₀ᵧ·t - ½g·t²

Igualando posiciones en tiempo t_i:
v_d₀ₓ = (x_e(t_i) - x_d₀)/t_i
v_d₀ᵧ = (y_e(t_i) - y_d₀ + ½g·t_i²)/t_i

2.4 Caso con Propulsor (Aceleración Adicional)

Misil Defensor con propulsor:
x_d(t) = x_d₀ + v_d₀ₓ·t + ½a_x·t²
y_d(t) = y_d₀ + v_d₀ᵧ·t + ½(a_y - g)·t²

Aceleración del propulsor:
a_propulsor = √(a_x² + a_y²)
Dirección hacia el punto de interceptación previsto

3. Análisis Funcional y Teórico

3.1 Criterios de Decisión

El sistema debe decidir entre dos estrategias basándose en:

🎯 Trayectoria Parabólica Simple

  • Altura de detección > 500m
  • Tiempo disponible > 5s
  • Velocidad requerida < 400 m/s
  • Ángulo factible (15° - 75°)

🚀 Con Propulsores

  • Altura de detección < 500m
  • Tiempo crítico < 5s
  • Velocidad requerida > 400 m/s
  • Ángulos extremos necesarios

3.2 Variables Estocásticas

Rangos de generación aleatoria:
x₀ ∈ [100, 2000] metros
y₀ ∈ [200, 1500] metros
|v₀| ∈ [100, 400] m/s
θ ∈ [15°, 75°] (ángulo de lanzamiento)
Dirección: aleatoria hacia objetivos terrestres

3.3 Función de Optimización

El sistema minimiza una función de costo que considera:

  • Tiempo de respuesta: Menor tiempo = mayor probabilidad de éxito
  • Consumo energético: Trayectoria simple vs. con propulsores
  • Precisión de interceptación: Margen de error aceptable
  • Factibilidad física: Limitaciones de aceleración y velocidad

5. Relación con el Sistema Domo de Hierro

El sistema desarrollado se inspira en el Iron Dome israelí, considerado uno de los sistemas de defensa antimisil más efectivos del mundo.

🛡️ Características del Iron Dome

  • Detecta proyectiles a 4-70 km de distancia
  • Tiempo de respuesta: 15-30 segundos
  • Tasa de éxito: ~90%
  • Intercepta solo amenazas a zonas pobladas
  • Usa radar y algoritmos predictivos

🎯 Nuestra Simulación

  • Modelo simplificado en 2D
  • Física clásica (gravedad únicamente)
  • Dos estrategias: simple y con propulsor
  • Variables estocásticas
  • Análisis de factibilidad en tiempo real
Innovación del modelo: Nuestro sistema incorpora la decisión automática entre trayectoria parabólica simple o con propulsores adicionales, optimizando recursos según las condiciones de detección.

6. Conclusiones

6.1 Logros del Proyecto

  • ✅ Reducción exitosa de 3D a 2D: Simplificación que mantiene la precisión física
  • ✅ Algoritmo de decisión adaptativo: Selección automática de estrategia óptima
  • ✅ Simulación interactiva funcional: Visualización en tiempo real de trayectorias
  • ✅ Implementación de variables estocásticas: Escenarios realistas y diversos
  • ✅ Análisis de factibilidad: Consideración de limitaciones físicas reales

6.2 Limitaciones y Mejoras Futuras

  • 🔄 Resistencia del aire: Podría incluirse para mayor realismo
  • 🔄 Múltiples amenazas: Gestión simultánea de varios proyectiles
  • 🔄 Incertidumbre en mediciones: Errores del radar y predicción
  • 🔄 Optimización de recursos: Minimización de interceptores utilizados
