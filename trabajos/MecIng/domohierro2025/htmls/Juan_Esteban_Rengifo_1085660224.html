Enunciado del problema

Un radar detecta un misil enemigo en vuelo. Se conocen su posición inicial \\(\\mathbf r_0\\), su velocidad inicial \\(\\mathbf v_0\\) y sus cosenos directores \\((\\ell,m,n)\\). El enemigo se mueve solo bajo gravedad terrestre. El sistema debe calcular la dirección y velocidad inicial con que lanzar el misil defensor. Si la detección ocurre alto respecto al suelo, bastará un tiro parabólico clásico; si ocurre muy cerca del suelo, el defensor deberá usar propulsores que agreguen una aceleración extra constante.

2

Solución algebraica propuesta

2.1 Reducción a 2D

El movimiento 3D del proyectil bajo gravedad \\(\\mathbf g = (0,-g,0)\\) siempre queda contenido en un plano: el generado por \\(\\mathbf v_0\\) y \\(\\mathbf g\\). Un vector normal al plano es \\(\\mathbf n = \\mathbf v_0 \\times \\mathbf g\\). Tomando una base ortonormal \\(\\{\\hat{\\mathbf e}_1,\\hat{\\mathbf e}_2\\}\\) sobre ese plano (por ejemplo, \\(\\hat{\\mathbf e}_1 = \\tfrac{\\mathbf v_0}{\\|\\mathbf v_0\\|}\\) y \\(\\hat{\\mathbf e}_2 = \\tfrac{\\mathbf n\\times\\hat{\\mathbf e}_1}{\\|\\mathbf n\\|}\\)), el problema se reduce a un tiro parabólico en coordenadas \\((x,y)\\) con \\(y\\) vertical.

2.2 Condiciones de intercepción (sin propulsor)

Denotemos \\(\\mathbf r_e(t) = \\mathbf r_{e0} + \\mathbf v_{e0} t + \\tfrac12 (0,-g) t^2\\) y \\(\\mathbf r_d(t) = \\mathbf r_{d0} + \\mathbf v_{d0} t + \\tfrac12 (0,-g) t^2\\). Como ambos tienen la misma aceleración, la gravedad se cancela en el movimiento relativo:

\\(\\;\\;\\mathbf r_e(t) - \\mathbf r_d(t) = (\\Delta \\mathbf r) + (\\Delta \\mathbf v)\\, t\\)
Intercepción \\(\\iff\\) existe \\(t>0\\) tal que \\((\\Delta \\mathbf r) + (\\Delta \\mathbf v)\\, t = \\mathbf 0\\).

Por tanto, para un tiempo de encuentro \\(t\\) cualquiera: \\(\\mathbf v_{d0}(t) = \\mathbf v_{e0} + \\tfrac{\\Delta \\mathbf r}{t}\\). El valor de \\(t\\) que minimiza \\(\\|\\mathbf v_{d0}\\|\\) es \\(t^* = \\tfrac{\\|\\Delta \\mathbf r\\|^2}{\\Delta \\mathbf r \\cdot \\mathbf v_{e0}}\\) (si \\(\\Delta \\mathbf r \\cdot \\mathbf v_{e0} > 0\\)).

2.3 Caso con propulsor (aceleración extra constante)

Si el defensor añade una aceleración constante \\(\\mathbf a_p = A\\, \\hat{\\mathbf u}\\) (módulo \\(A\\), dirección fija \\(\\hat{\\mathbf u}\\)), entonces \\(\\mathbf r_d(t) = \\mathbf r_{d0} + \\mathbf v_{d0} t + \\tfrac12 ((0,-g)+ \\mathbf a_p) t^2\\). Imponiendo \\(\\mathbf r_d(T)=\\mathbf r_e(T)\\) para un tiempo de encuentro \\(T\\), se obtiene

\\(\\mathbf v_{d0}(T,\\hat{\\mathbf u}) = \\dfrac{\\mathbf r_e(T) - \\mathbf r_{d0} - \\tfrac12\\big((0,-g)+A\\hat{\\mathbf u}\\big)T^2}{T}\\).

La estrategia numérica adoptada es buscar \\(T\\) (y, si aplica, \\(\\hat{\\mathbf u}\\)) que minimicen \\(\\|\\mathbf v_{d0}\\|\\) bajo restricciones de velocidad máxima y aceleración disponibles.

3

Análisis funcional / teórico

  • La detección “alta” permite intercepción puramente balística (gravedad en ambos cancela en el marco relativo).
  • La detección “cerca del suelo” exige acortar el tiempo de encuentro \\(T\\), elevando la velocidad inicial requerida; para mantenerla dentro de límites físicos, se activa una aceleración extra constante.
  • La intercepción se verifica si la distancia entre trayectorias cae por debajo de un umbral (p. ej., 5 m).
  • En la práctica, se impone \\(v_{d0} \\le v_{\\max}\\) y \\(A \\le A_{\\max}\\); si no hay solución, se reporta “no alcanzable”.
4

Planteamiento de la simulación

Se generan aleatoriamente \\(\\mathbf r_{e0}\\), \\(\\mathbf v_{e0}\\) y cosenos directores \\((\\ell,m,n)\\) dentro de rangos razonables: posiciones en centenas de metros, velocidades entre 100–400 m/s y ángulos 15°–75°. La simulación se resuelve en el plano 2D que contiene la trayectoria, y permite forzar el uso de propulsor. El cálculo automático escoge \\(T\\) (y la dirección de empuje) que minimizan la velocidad inicial requerida del defensor con las restricciones impuestas.

Relación con el sistema Domo de Hierro

  • Este modelo ilustra el principio de cálculo de punto de encuentro bajo simplificaciones (gravedad uniforme, viento nulo).
  • Un sistema real emplea estimación de estado 3D con sensores, guiado proporcional (PN), control en lazo cerrado y propulsión variable.
  • La decisión de usar propulsor aquí se basa en la altura de detección; en sistemas reales depende de múltiples criterios (tiempo-amenaza, alcance, cinemática).
7

Conclusiones

  • La reducción a 2D simplifica el análisis y la simulación sin perder generalidad.
  • En el caso sin propulsor, la gravedad se cancela en el marco relativo y la condición clave es lineal en el tiempo.
  • Cuando el tiempo disponible es pequeño (detección baja), la aceleración adicional reduce el requerimiento de velocidad inicial.
  • El algoritmo numérico (búsqueda sobre T y dirección de empuje) halla soluciones factibles dentro de límites físicos.
