1. Introducción

En esta simulación se modela la intercepción de un proyectil enemigo mediante un proyectil defensor, como una analogía simplificada del sistema Domo de Hierro.

2. Marco Teórico

El movimiento de los proyectiles se describe con las ecuaciones de la cinemática bajo aceleración constante:

\[ \vec{r}_e(t) = \vec{r}_{e0} + \vec{v}_{e0} t + \tfrac{1}{2} \vec{g} t^2 \] \[ \vec{r}_d(t) = \vec{r}_{d0} + \vec{v}_{d0} t + \tfrac{1}{2} \vec{g} t^2 \]

3. Formulación Matemática

Para la intercepción se requiere que en un instante \(t\):

\[ (x_e(t), y_e(t)) = (x_d(t), y_d(t)) \]

4. Planteamiento de la Simulación

Se generan aleatoriamente parámetros del enemigo dentro de rangos razonables y se simulan trayectorias para el enemigo y el defensor, verificando si ocurre intercepción.

5. Simulación Interactiva

Velocidad enemigo (m/s): 50
Ángulo enemigo (°): 45
Velocidad defensor (m/s): 60
Ángulo defensor (°): 60

6. Relación con el Sistema Domo de Hierro

El sistema "Domo de Hierro" (Iron Dome) de Israel es un análogo real a esta simulación. Detecta trayectorias, decide si amenazan zonas pobladas y lanza interceptores maniobrables.

7. Conclusiones

El modelo muestra cómo parámetros iniciales (velocidad y ángulo) determinan la posibilidad de intercepción. Aunque simplificado, ayuda a comprender los principios físicos involucrados.
