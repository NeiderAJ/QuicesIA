1. Enunciado del Problema Cinematográfico

En el contexto de la defensa aeroespacial, el problema fundamental radica en la predicción exacta de una trayectoria parabólica bajo la influencia de un campo gravitatorio uniforme. Un proyectil enemigo es detectado con una velocidad inicial \(v_0\) y una orientación definida por los cosenos directores \((l, m, n)\).

La tarea del sistema es calcular, en tiempo real, el vector de lanzamiento de un misil interceptor que parte desde el origen de coordenadas o una base cercana. El sistema debe compensar factores como la aceleración de propulsión adicional y garantizar que la colisión ocurra antes de que el objetivo alcance su punto de impacto en tierra (\(y=0\)).

2. Desarrollo Algebraico y Modelado

Para el análisis bidimensional, descomponemos la velocidad inicial en sus componentes rectangulares:

\[ v_{xe} = v_0 \cdot l \quad ; \quad v_{ye} = v_0 \cdot m \] \[ \text{Donde } l^2 + m^2 = 1 \text{ (en 2D)} \]

Ecuaciones de Posición del Objetivo:

\[ x_e(t) = x_{0e} + (v_0 \cdot l)t \] \[ y_e(t) = y_{0e} + (v_0 \cdot m)t - \frac{1}{2}gt^2 \]

Ecuaciones del Interceptor (Propulsión Asistida):

El defensor incorpora una aceleración neta \(a_{net} = a_p - g\) en el eje vertical:

\[ x_d(t) = x_{0d} + v_{xd}t \] \[ y_d(t) = y_{0d} + v_{yd}t + \frac{1}{2}(a_p - g)t^2 \]

3. Análisis Funcional del Simulador

El sistema opera bajo una arquitectura de "Detección y Respuesta":

  • Optimización de Inicio: El radar ajusta la altura de aparición del enemigo según su ángulo de ataque para mantener la trayectoria dentro del rango visual (450m).
  • Cálculo de Colisión: Se utiliza un algoritmo de persecución proporcional donde el interceptor ajusta su vector velocidad hacia la posición futura del enemigo.
  • Límites Operativos: El sistema cancela la operación si el objetivo supera el "techo" del radar o impacta el suelo.

6. Relación con el sistema Domo de Hierro

El sistema de defensa conocido como Iron Dome utiliza radares avanzados para detectar proyectiles enemigos y calcular su trayectoria en tiempo real. A partir de esta información el sistema determina si el misil representa una amenaza y calcula la trayectoria que debe seguir un interceptor para destruir el proyectil en el aire.

La simulación representada en este trabajo reproduce de manera simplificada los principios físicos fundamentales en este tipo de sistemas de defensa, utilizando ecuaciones del movimiento parabólico y métodos de simulación computacional.

7. Conclusiones

La reducción del problema tridimensional a un plano bidimensional permite simplificar el análisis matemático de la trayectoria.

La simulación computacional permite visualizar de forma clara el proceso de interceptación entre dos proyectiles.

El uso de parámetros ajustables facilita el análisis del efecto de la gravedad y aceleración adicional en la dinámica del sistema.
