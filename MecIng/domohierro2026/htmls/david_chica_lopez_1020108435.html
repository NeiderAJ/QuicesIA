Sistema de Intercepción de Misiles

Proyecto de Física Mecánica - Universidad de Antioquia

1. Enunciado del Problema

Un radar detecta un misil enemigo con una posición inicial \(\vec{r}_0\) y velocidad \(\vec{v}_0\), definidos en un espacio tridimensional mediante cosenos directores \((l, m, n)\). El objetivo es reducir el problema a un plano bidimensional para calcular la trayectoria de interceptación de un misil defensor.

  • Caso A: Detección a gran altura (Tiro parabólico clásico).
  • Caso B: Detección a baja altura (Uso de propulsores con aceleración adicional).

2. Solución Algebraica

Reducción a 2D

Cualquier proyectil bajo la única influencia de la gravedad \(\vec{g} = (0, 0, -g)\) se mueve en un plano vertical. Si la velocidad inicial es \(\vec{v}_0 = (v_x, v_y, v_z)\), el plano de movimiento está definido por el vector velocidad y el vector gravedad. Definimos la distancia horizontal radial como: \[ \rho = \sqrt{x^2 + y^2} \] Así, las ecuaciones de posición se reducen a: \[ \rho(t) = \rho_0 + v_{\rho 0}t \] \[ z(t) = z_0 + v_{z0}t - \frac{1}{2}gt^2 \]

Condición de Intercepción

Para que el misil defensor impacte al enemigo en un tiempo \(t_i\), se debe cumplir que: \[ \vec{r}_e(t_i) = \vec{r}_d(t_i) \] Si se requiere propulsión adicional (\(\vec{a}_p\)), la ecuación del defensor cambia a: \[ z_d(t) = z_{d0} + v_{zd0}t + \frac{1}{2}(a_p - g)t^2 \]

Relación con el Domo de Hierro

El sistema Iron Dome utiliza radares avanzados para detectar amenazas en un rango de 4 a 70 km. Al igual que en este modelo, el sistema predice la trayectoria parabólica. Si el punto de impacto calculado cae en una zona poblada, lanza un misil interceptor (Tamir). Nuestra lógica de "propulsores" emula la capacidad de maniobra de estos misiles para corregir su curso en tiempo real.

Conclusiones

  • La reducción de 3D a 2D simplifica drásticamente el costo computacional de la interceptación.
  • El uso de aceleración extra es crítico cuando el tiempo de reacción es limitado por la baja altitud.
  • La aleatoriedad representa la incertidumbre real de los campos de batalla.
